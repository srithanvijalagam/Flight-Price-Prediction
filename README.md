# Flight-Price-Prediction
A Machine Learning-based Flight Price Prediction application built using Python, Scikit-learn, and Streamlit. It uses a trained Random Forest Regressor to estimate flight ticket prices based on airline, source, destination, travel class, duration, and other flight details.
